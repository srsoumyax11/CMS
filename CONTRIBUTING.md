# Contributing to BPUT CMS

First off, thank you for considering contributing to BPUT CMS! It's people like you that make this tool such a great platform.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/srsoumyax11/CMS/issues) to see if it has already been reported. If not, feel free to open a new issue!

## Development Setup

To set up the project locally for development, please follow our [Setup Guide](./docs/SETUP.md).

## Pull Request Process

1. Fork the repo and create your branch from `main`.
2. Ensure you have installed the dependencies and run local tests.
3. If you've added code that should be tested, add tests.
4. Ensure the test suite passes.
5. Update the documentation in the `docs/` folder if you change any architecture, API, or database schema.
6. Issue that pull request!

## Code Style

- **Frontend**: We use Prettier and ESLint. Run `npm run lint` before committing.
- **Backend**: We follow PEP 8. Please run `black` and `flake8` before committing.

Thank you for your contributions!
